§Common Module

This module contains common constants and utility functions used across the SP1 circuits in the Clementine protocol. It includes definitions for constants related to the bridge amount, number of outputs, transaction assertions, and watchtowers. It also provides hashing functions for cryptographic operations, such as double SHA256 and single SHA256 hashing, as well as a utility function to hash two nodes together. The ZkvmGuest trait defines the guest interface for reading from the host, committing data and verifying proofs.
