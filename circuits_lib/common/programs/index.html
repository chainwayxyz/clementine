Module programs 

Source
Expand description

SP1 program keys used together on each Bitcoin network.

scripts/build_sp1_guests.py generates the keys in super::sp1_programs. With use-test-vk, non-mainnet networks use the development bridge guest, which verifies watchtower proofs with the development Groth16 key. The other guests are the same in both builds.

Structs§

NetworkPrograms
SP1 program keys of the guests that one Bitcoin network uses together.
ProgramKey
Identifier of an SP1 program: the digest of its verifying key, which is eight KoalaBear field elements. SP1 has two encodings of this digest, because its two verifiers work over different fields. scripts/build_sp1_guests.py generates both from the program ELFs, so no code converts between them; generated_key_encodings_match_sp1 checks that they agree.
