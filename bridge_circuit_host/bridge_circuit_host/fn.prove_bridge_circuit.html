Expand description

Proves the network’s bridge guest and returns a Groth16 proof for BitVM.

The host first checks the header chain proof, the light client proof and the SPV inclusion, so that invalid inputs fail before proving. With Backend::Mock, the guest is executed and a development Groth16 proof is created instead. Either proof is checked against the BitVM verifying key of the bridge program.

Returns the Groth16 proof and the values the operator commits for BitVM, whose BridgeCircuitBitvmInputs::groth16_public_input is the proof’s public input.
