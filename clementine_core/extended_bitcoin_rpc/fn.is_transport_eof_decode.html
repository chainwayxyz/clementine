Function is_transport_eof_decode 

Source 
fn is_transport_eof_decode(error: &Error) -> bool
Expand description

Returns true if a decode-kind reqwest error was caused by the connection dropping mid-response (transport EOF) instead of a malformed or empty (e.g. HTTP 401/404) response body. reqwest’s Decoder reports a body closed before its Content-Length completes as is_decode, with a hyper::Error (incomplete message) or a connection-drop io::Error source; genuine JSON syntax errors have a plain serde_json::Error source instead.
